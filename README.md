# Склад Массивбург на iPhone

Откройте [мобильное приложение](https://massivburg-sklad-phone.putyn-k-a.chatgpt.site) в Safari под своим аккаунтом ChatGPT. Выберите **«Поделиться» → «На экран Домой»**, включите **«Открывать как веб‑приложение»**, если Safari показывает этот переключатель, и нажмите **«Добавить»**.

1. Выберите Excel-заявку конструктора из «Файлов» (`.xlsx` или `.xlsm`).
2. Добавьте Excel-выгрузку **«Закупки»** и полный JSON из **«Сверка склада» → «Реестр» → «Скачать реестр (json)»**. Они запоминаются на устройстве. Заменяйте их после обновления данных. Даты файлов видны на экране.
3. Для спорных совпадений разверните **DeepSeek** и введите ключ API. Ключ хранится в памяти открытого окна. В API уходят описания, артикулы и единицы измерения спорных строк и их кандидатов.
4. Нажмите **«Проверить заявку»**. Нажмите на **«Основание и источники»** под позицией, чтобы увидеть расчёт и кандидатов. Программа показывает, сколько можно взять, с какой полки и сколько докупить. Результат сохраняется в Excel через меню iPhone.

Расчёт использует свободный остаток из столбца K листа «Склад» и проверенное количество с адресом из реестра. Неоднозначное совпадение, неизвестное количество или расхождение между источниками требуют ручной проверки. Сверка расходует остаток один раз в пределах заявки. Программа работает с локальными снимками данных. Журнал и снимки хранятся отдельно для каждого адреса приложения в IndexedDB. Журнал можно сохранить в JSON через вкладку **«Журнал»**.

Для публикации на GitHub Pages выберите **Settings → Pages → Deploy from a branch → main → / (root)**. Для локальной проверки можно запустить `python -m http.server 8080` в корне репозитория. Корневые файлы и `assets/` образуют статическое приложение. SheetJS 0.20.3 подключён локально, лицензия находится в `assets/SHEETJS-LICENSE.txt`.
